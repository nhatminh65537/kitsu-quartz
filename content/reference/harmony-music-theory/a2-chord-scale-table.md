## 1. Major Key — ii–V–I Chord-Scale Mapping

| Chord (key C) | Roman | Scale | Mode Name | Avoid Notes |
|--------------|-------|-------|-----------|-------------|
| Dm7 | ii | D–E–F–G–A–B–C | **D Dorian** | B♭ (♭6 = avoid) |
| G7 | V (natural) | G–A–B–C–D–E–F | **G Mixolydian** | C (♮11 = avoid) |
| G7alt | V (altered) | G–A♭–B♭–C♭–D♭–E♭–F | **G Altered** (7th mode mel. minor) | — |
| G13 | V (unaltered ext) | G Mixolydian | same | — |
| G7#11 | V (Lydian dom) | G–A–B–C#–D–E–F | **G Lydian Dominant** (4th mode mel. minor) | — |
| Cmaj7 | I | C–D–E–F–G–A–B | **C Ionian** | F (♮11 = avoid on maj7) |
| Cmaj7#11 | I Lydian | C–D–E–F#–G–A–B | **C Lydian** | — (F# is characteristic!) |

## 2. Minor Key — ii–V–i Chord-Scale Mapping

| Chord (key Cm) | Roman | Scale | Mode Name | Notes |
|---------------|-------|-------|-----------|-------|
| Dm7♭5 | iiø | D–E–F–G–A♭–B♭–C | **D Locrian** | Natural 9 possible |
| Dm7♭5 | iiø (alt) | D–E♭–F–G–A♭–B♭–C | **D Locrian ♮2** (6th mode mel. minor) | Brighter sound |
| G7 | V (minor) | G–A♭–B♭–B♮–C–D♭–E♭–F | **G HM5** (5th mode harmonic minor) | Standard |
| G7alt | V (altered) | G Altered scale | same as above | Most tension |
| Cm7 | i (Aeolian) | C–D–E♭–F–G–A♭–B♭ | **C Aeolian** | Natural minor |
| Cm(maj7) | i (melodic) | C–D–E♭–F–G–A–B | **C Melodic Minor** | Ascending |

## 3. Tất Cả Chord Types — Scale Reference

### Dominant 7th Chords (nhiều lựa chọn nhất)

| Chord Symbol | Scale | Character |
|-------------|-------|-----------|
| X7 (natural) | X Mixolydian | Blues, straightforward |
| X7#11 | X Lydian Dominant | Floating, Bossa, Modern |
| X7♭9 | X Half-Whole Diminished | Minor context, dark |
| X7#9 | X Whole-Tone hoặc Altered | Blues-rock, Hendrix |
| X7alt | X Altered (Super Locrian) | Maximum tension, Jazz |
| X7♭13 | X Mixolydian♭6 (5th mode mel. min) | Minor subdominant feel |
| X7sus4 | X Mixolydian | Suspended, no 3rd |

### Major 7th Chords

| Chord Symbol | Scale | Character |
|-------------|-------|-----------|
| Xmaj7 | X Ionian (major) | Standard |
| Xmaj7#11 | X Lydian | Dreamy, floating |
| Xmaj7#5 | X Lydian Augmented (3rd mode mel. min) | Unusual, ethereal |

### Minor 7th Chords

| Chord Symbol | Scale | Character |
|-------------|-------|-----------|
| Xm7 | X Dorian | Bright minor (natural 6) |
| Xm7 (nat. minor) | X Aeolian | Dark minor (♭6) |
| Xm7 (Phrygian) | X Phrygian | Very dark (♭2) |
| Xm(maj7) | X Melodic Minor | Tense, ascending |

### Half-Diminished & Diminished

| Chord Symbol | Scale | Character |
|-------------|-------|-----------|
| Xø7 (m7♭5) | X Locrian | Most common |
| Xø7 (alt) | X Locrian ♮2 | Brighter half-dim |
| X°7 | X Whole-Half Diminished | Symmetrical, 4 resolutions |
| X°7 | X Half-Whole Diminished | Over dominant context |

## 5. Melodic Minor Modes — Jazz Applications

Melodic minor = 1–2–♭3–4–5–6–7 (ascending only in Jazz)

| Mode | Tên gọi | Chord | Dùng khi |
|------|---------|-------|---------|
| 1st | C Melodic Minor | Cm(maj7) | Tonic minor với leading tone |
| 2nd | Dorian ♭2 (Phrygian ♮6) | Dm7♭5(♮9) | iiø7 trong minor, brighter |
| 3rd | Lydian Augmented | Emaj7#5 | Tonic major với #5 |
| 4th | Lydian Dominant | F7#11 | V7 dẫn về Bb, Bossa color |
| 5th | Mixolydian ♭6 (HM5) | G7♭13 | V7 trong minor key |
| 6th | Aeolian ♭5 (Locrian ♮2) | Am7♭5 | iiø7 trong minor, richer |
| 7th | Super Locrian (Altered) | B7alt | V7alt, maximum tension |

---

## 6. Harmonic Minor Modes

Harmonic minor = 1–2–♭3–4–5–♭6–7

| Mode | Tên gọi | Ứng dụng |
|------|---------|---------|
| 1st | Harmonic Minor | im(maj7) |
| 2nd | Locrian ♮6 | iiø7 với natural 6 |
| 3rd | Ionian #5 | ♭IIImaj7#5 |
| 4th | Dorian #4 | ivm7#4 (unusual) |
| 5th | Phrygian Dominant | V7 trong minor = **tango, flamenco** |
| 6th | Lydian #2 | ♭VImaj7#2 |
| 7th | Super Locrian ♭♭7 | vii°7 |

**Mode 5 (Phrygian Dominant)** = E–F–G#–A–B–C–D trong A minor. Dùng cho E7 chord khi resolve về Am. Đây là âm thanh Tango và Flamenco.
