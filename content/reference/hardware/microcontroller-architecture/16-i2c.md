## Motivation

I2C chỉ cần 2 dây (SDA + SCL) nhưng hỗ trợ tới 127 device trên cùng một bus nhờ addressing scheme. Đây là lý do I2C phổ biến trong sensor (IMU, temperature, pressure), EEPROM, RTC, và display controller. Từ góc độ hardware hacking, I2C bus trên PCB thường kết nối nhiều component quan trọng — sniff I2C có thể tiết lộ key material đọc từ EEPROM, cấu hình bảo mật từ secure element, hay sensor data ảnh hưởng đến decision của hệ thống.

## I2C Protocol — Cơ chế Hoạt động

### Open-Drain Bus và Pull-up

> [!definition] Definition 16.1 — I2C Electrical Characteristics
> Cả SDA và SCL đều là **open-drain**: mỗi device chỉ có thể kéo line xuống LOW (drain transistor), không thể drive HIGH. HIGH đến từ **pull-up resistor** bên ngoài nối lên VCC.
>
> ```text
> VCC (3.3V)
>  │    │
> [Rp] [Rp]    ← Pull-up resistors (4.7kΩ cho 100kHz, 2.2kΩ cho 400kHz)
>  │    │
> SDA  SCL    ← Bus lines
>  │    │
> [↓] [↓]   ← Open-drain outputs từ nhiều device
> ```
>
> Giá trị pull-up ảnh hưởng tốc độ: quá lớn → rise time chậm → không đạt Fast Mode. Quá nhỏ → tiêu điện nhiều, có thể không kéo xuống LOW đủ.

### START, STOP và Data Transfer

> [!definition] Definition 16.2 — I2C Bus Conditions
>
> ```text
> Idle:    SDA=HIGH, SCL=HIGH (cả hai line ở HIGH)
>
> START:   SDA HIGH→LOW trong khi SCL=HIGH
>          ────────┐
>     SDA:         └────────────
>          ─────────────┐
>     SCL:              └───────
>                    ↑START
>
> STOP:    SDA LOW→HIGH trong khi SCL=HIGH
>     SDA: ─────────┐  ┌─────
>                   └──┘
>     SCL: ──────┐     ┌─────
>                └─────┘
>                      ↑STOP
>
> Data bit: SDA phải ổn định khi SCL=HIGH
>     SDA: ────┤  bit  ├────
>     SCL:     └──────┘
>              sample khi HIGH
> ```

### Frame Format — 7-bit Addressing

```text
[START][ADDR 7-bit][R/W][ACK][DATA byte][ACK]...[DATA byte][ACK/NACK][STOP]

Write transaction (master → slave):
S  A6 A5 A4 A3 A2 A1 A0  0  A  D7 D6 D5 D4 D3 D2 D1 D0  A  P
↑START ←── address ──→ W  ↑    ←────── data ───────────→    ↑STOP
                         ACK                              ACK
Read transaction (master ← slave):
S  A6 A5 A4 A3 A2 A1 A0  1  A  D7 D6 D5 D4 D3 D2 D1 D0  N  P
↑START ←── address ──→ R ↑   ←────── data (slave drives) ──→
                        ACK                              NACK (last byte)
```

> [!definition] Definition 16.3 — ACK và NACK
> Sau mỗi byte được truyền, receiver kéo SDA xuống LOW trong clock pulse thứ 9 = **ACK** (acknowledge). Nếu SDA vẫn HIGH = **NACK** (no acknowledge), có nghĩa:
> - Slave không tồn tại ở address đó (address scan)
> - Slave bận (đang xử lý) và dùng clock stretching
> - Slave không muốn nhận thêm data (master gửi NACK ở byte cuối khi đọc)

### Clock Stretching

Slave có thể **hold SCL xuống LOW** để yêu cầu master dừng lại — gọi là clock stretching. Master phải chờ cho đến khi SCL được release.

```text
Master: SCL ─┐  ┌──────────────────────────┐  ┌──
              └──┘                          └──┘
Slave:  SCL ─┐  ┌────┐ ← slave kéo LOW     ┌──┐──
              └──┘    └────────────────────┘
                      ↑ stretch             ↑ release
```

## I2C Registers STM32F4

> [!definition] Definition 16.4 — I2C Register Set
>
> | Register | Offset | Chức năng |
> |----------|--------|-----------|
> | `CR1`  | 0x00 | PE (enable), ACK, START, STOP, SWRST (software reset) |
> | `CR2`  | 0x04 | FREQ[5:0] — peripheral clock freq (MHz), ITERREN, ITEVTEN, ITBUFEN |
> | `OAR1` | 0x08 | Own Address 1 (slave mode) |
> | `OAR2` | 0x0C | Own Address 2 (dual address) |
> | `DR`   | 0x10 | Data Register: ghi = transmit, đọc = receive |
> | `SR1`  | 0x14 | SB, ADDR, BTF, TXE, RXNE, AF, ARLO, BERR, OVR |
> | `SR2`  | 0x18 | MSL (1=master), BUSY, TRA (1=transmitter) |
> | `CCR`  | 0x1C | Clock Control Register — set tốc độ |
> | `TRISE`| 0x20 | Maximum rise time |

**SR1 — Status Register 1, các bit quan trọng**:

```text
Bit 0:  SB    — Start Bit generated (START condition sent)
Bit 1:  ADDR  — Address sent (master) / matched (slave)
Bit 2:  BTF   — Byte Transfer Finished
Bit 4:  TXE   — TX buffer empty (có thể ghi DR)
Bit 6:  RXNE  — RX buffer not empty (có data để đọc)
Bit 8:  BERR  — Bus Error (START/STOP trong sai vị trí)
Bit 9:  ARLO  — Arbitration Lost
Bit 10: AF    — Acknowledge Failure (NACK nhận được)
Bit 11: OVR   — Overrun/Underrun
```

## Cấu hình I2C1 Master — Standard Mode 100 kHz

```c
/* I2C1: PB8=SCL, PB9=SDA (AF4), APB1=42MHz */

void i2c1_init(void) {
    /* 1. Enable clocks */
    RCC->AHB1ENR |= RCC_AHB1ENR_GPIOBEN;
    RCC->APB1ENR |= RCC_APB1ENR_I2C1EN;

    /* 2. GPIO: PB8=SCL, PB9=SDA — AF4, open-drain, pull-up, high speed */
    uint8_t i2c_pins[] = {8, 9};
    for (int i = 0; i < 2; i++) {
        uint8_t pin = i2c_pins[i];
        GPIOB->MODER  &= ~(3U << (pin*2));
        GPIOB->MODER  |=  (2U << (pin*2));       /* AF mode */
        GPIOB->OTYPER |=  (1U << pin);            /* Open-drain — bắt buộc */
        GPIOB->OSPEEDR|=  (3U << (pin*2));        /* High speed */
        GPIOB->PUPDR  &= ~(3U << (pin*2));
        GPIOB->PUPDR  |=  (1U << (pin*2));        /* Pull-up */
        GPIOB->AFR[1] &= ~(0xFU << ((pin-8)*4));
        GPIOB->AFR[1] |=  (4U   << ((pin-8)*4)); /* AF4 = I2C1 */
    }

    /* 3. Reset I2C peripheral */
    I2C1->CR1 |= I2C_CR1_SWRST;
    I2C1->CR1 &= ~I2C_CR1_SWRST;

    /* 4. CR2: peripheral clock = 42 MHz */
    I2C1->CR2 = 42U;                             /* FREQ = 42 (MHz) */

    /* 5. CCR: Standard Mode (SM), 100 kHz
     * CCR = f_PCLK / (2 * f_SCL) = 42,000,000 / (2 * 100,000) = 210 */
    I2C1->CCR = 210U;                            /* SM mode, CCR=210 */

    /* 6. TRISE: max rise time = 1000ns tại Standard Mode
     * TRISE = (t_rise / t_PCLK) + 1 = (1000ns × 42MHz) + 1 = 43 */
    I2C1->TRISE = 43U;

    /* 7. Enable I2C */
    I2C1->CR1 |= I2C_CR1_PE;
}
```

## I2C Master Write và Read

```c
/* Gửi START condition và chờ SB bit */
static void i2c1_start(void) {
    I2C1->CR1 |= I2C_CR1_ACK | I2C_CR1_START;
    while (!(I2C1->SR1 & I2C_SR1_SB)) { }
}

/* Gửi STOP condition */
static void i2c1_stop(void) {
    I2C1->CR1 |= I2C_CR1_STOP;
    while (I2C1->SR2 & I2C_SR2_BUSY) { }   /* Chờ bus rảnh */
}

/* Gửi address + direction (0=Write, 1=Read), chờ ADDR */
static int i2c1_send_addr(uint8_t addr_7bit, uint8_t read) {
    I2C1->DR = (uint8_t)((addr_7bit << 1) | (read & 1));
    uint32_t timeout = 100000;
    while (!(I2C1->SR1 & I2C_SR1_ADDR)) {
        if (I2C1->SR1 & I2C_SR1_AF) {
            I2C1->SR1 &= ~I2C_SR1_AF;      /* Clear AF */
            i2c1_stop();
            return -1;                       /* NACK — device không tồn tại */
        }
        if (!timeout--) return -1;
    }
    /* Clear ADDR bằng cách đọc SR1 rồi SR2 */
    (void)(I2C1->SR1);
    (void)(I2C1->SR2);
    return 0;
}

/* Write: gửi len bytes từ buf đến slave addr_7bit */
int i2c1_write(uint8_t addr, const uint8_t *buf, uint32_t len) {
    i2c1_start();
    if (i2c1_send_addr(addr, 0) != 0) return -1;   /* 0=Write */

    for (uint32_t i = 0; i < len; i++) {
        while (!(I2C1->SR1 & I2C_SR1_TXE)) { }     /* Chờ TXE */
        I2C1->DR = buf[i];
    }
    while (!(I2C1->SR1 & I2C_SR1_BTF)) { }         /* Chờ last byte xong */
    i2c1_stop();
    return 0;
}

/* Read: nhận len bytes từ slave addr_7bit vào buf */
int i2c1_read(uint8_t addr, uint8_t *buf, uint32_t len) {
    i2c1_start();
    if (i2c1_send_addr(addr, 1) != 0) return -1;   /* 1=Read */

    for (uint32_t i = 0; i < len; i++) {
        if (i == len - 1) {
            /* Byte cuối: disable ACK → master gửi NACK sau byte này */
            I2C1->CR1 &= ~I2C_CR1_ACK;
            i2c1_stop();                            /* STOP sau byte cuối */
        }
        while (!(I2C1->SR1 & I2C_SR1_RXNE)) { }    /* Chờ data */
        buf[i] = (uint8_t)I2C1->DR;
    }
    /* Re-enable ACK cho transaction tiếp theo */
    I2C1->CR1 |= I2C_CR1_ACK;
    return 0;
}

/* Write rồi Read (repeated START — phổ biến để set register pointer) */
int i2c1_write_read(uint8_t addr,
                    const uint8_t *wbuf, uint32_t wlen,
                    uint8_t *rbuf, uint32_t rlen) {
    i2c1_start();
    if (i2c1_send_addr(addr, 0) != 0) return -1;
    for (uint32_t i = 0; i < wlen; i++) {
        while (!(I2C1->SR1 & I2C_SR1_TXE)) { }
        I2C1->DR = wbuf[i];
    }
    while (!(I2C1->SR1 & I2C_SR1_BTF)) { }
    /* Repeated START (không STOP) */
    i2c1_start();
    if (i2c1_send_addr(addr, 1) != 0) return -1;
    for (uint32_t i = 0; i < rlen; i++) {
        if (i == rlen - 1) {
            I2C1->CR1 &= ~I2C_CR1_ACK;
            i2c1_stop();
        }
        while (!(I2C1->SR1 & I2C_SR1_RXNE)) { }
        rbuf[i] = (uint8_t)I2C1->DR;
    }
    I2C1->CR1 |= I2C_CR1_ACK;
    return 0;
}
```

## I2C Bus Scan — Tìm Device Address

```c
/* Quét toàn bộ 127 địa chỉ, in những địa chỉ có response ACK */
void i2c1_scan(void) {
    uint8_t found[128] = {0};
    uint8_t count = 0;

    for (uint8_t addr = 1; addr < 127; addr++) {
        i2c1_start();
        int ret = i2c1_send_addr(addr, 0);   /* Write probe */
        i2c1_stop();

        if (ret == 0) {
            found[count++] = addr;
        }
    }
    /* In kết quả: found[0..count-1] là các địa chỉ có device */
    (void)found; (void)count;
}
```

**I2C Scanner bằng Python với USB adapter**:

```python
import smbus2

bus = smbus2.SMBus(1)   # /dev/i2c-1 trên Raspberry Pi
print("Scanning I2C bus...")
found = []
for addr in range(0x03, 0x78):
    try:
        bus.read_byte(addr)
        found.append(addr)
        print(f"  Device found at 0x{addr:02X}")
    except OSError:
        pass
print(f"Found {len(found)} device(s)")
bus.close()
```

**Địa chỉ I2C phổ biến**:

| Device | Address | Ghi chú |
|--------|---------|---------|
| MPU-6050 (IMU) | 0x68 hoặc 0x69 | Phụ thuộc AD0 pin |
| DS3231 (RTC) | 0x68 | |
| BMP280 (pressure) | 0x76 hoặc 0x77 | |
| SSD1306 (OLED) | 0x3C hoặc 0x3D | |
| AT24Cxx (EEPROM) | 0x50–0x57 | 3 bit địa chỉ cấu hình qua pin |
| PCF8574 (GPIO expander) | 0x20–0x27 | |
| Secure Element (ATECC608) | 0x60 | Lưu crypto key |

## I2C Attack Surface

> [!warning] Security Note — I2C Sniffing và Injection
>
> **Sniffing**: I2C là shared open-drain bus — bất kỳ device nào trên bus đều "nghe" mọi transaction. Gắn logic analyzer vào SDA/SCL → decode toàn bộ traffic.
>
> Mục tiêu sniff:
> - EEPROM đọc key/credential khi boot
> - Secure element trả về nonce/token
> - Sensor data ảnh hưởng đến security decision (ví dụ: "mở khóa nếu nhiệt độ < X")
>
> **Injection / Impersonation**: Attacker có thể "impersonate" một I2C slave bằng cách:
> 1. Cắt trace PCB giữa slave và master
> 2. Kết nối thiết bị giả vào đúng địa chỉ
> 3. Trả về data giả mạo
>
> **Clock Stretching Abuse**: Slave độc hại có thể hold SCL xuống LOW vô thời hạn → treo master (Denial of Service). Firmware tốt phải có timeout khi chờ SCL release.
>
> **Address Collision**: Nếu hai device có cùng địa chỉ (một số sensor không cho phép thay đổi địa chỉ), arbitration sẽ gây ra bus error.

## Summary

- I2C dùng 2 dây open-drain (SDA + SCL) với pull-up resistor bên ngoài. Idle = cả hai HIGH.
- **START**: SDA HIGH→LOW khi SCL HIGH. **STOP**: SDA LOW→HIGH khi SCL HIGH. Data chỉ thay đổi khi SCL LOW.
- Frame: START + 7-bit address + R/W bit + ACK + data bytes + ACK/NACK + STOP.
- **ACK** = SDA LOW sau byte (receiver kéo xuống). **NACK** = SDA HIGH (không ai kéo xuống).
- **Clock stretching**: slave hold SCL LOW để yêu cầu master chờ — firmware phải có timeout.
- Cấu hình STM32F4 I2C1: set FREQ (MHz) trong CR2, tính CCR = fPCLK/(2×fSCL), tính TRISE = (t_rise×fPCLK)+1.
- **I2C scan**: thử từng address 0x01–0x7E, địa chỉ nào ACK = có device. Phổ biến để discover hardware.
- **Security**: shared bus → sniff trivial. Impersonate slave → inject fake data. Clock stretching vô hạn → DoS.
