## Bài toán: Age Proof

**Mục tiêu**: Prover chứng minh họ đủ 18 tuổi mà không tiết lộ tuổi chính xác.

**Public inputs**:
- `min_age = 18` (threshold)
- `current_year = 2026`

**Private inputs**:
- `birth_year` (năm sinh, private)

**Statement**: $\text{current\_year} - \text{birth\_year} \geq \text{min\_age}$

Tương đương: tồn tại $k \geq 0$ sao cho $\text{current\_year} - \text{birth\_year} - \text{min\_age} = k$

---

## Bước 1: Viết Circuit

```circom
pragma circom 2.0.0;

include "node_modules/circomlib/circuits/comparators.circom";

// Chứng minh age >= min_age
// Public: min_age, current_year
// Private: birth_year
template AgeProof() {
    signal input birth_year;    // private: năm sinh
    signal input current_year;  // public: năm hiện tại
    signal input min_age;       // public: tuổi tối thiểu

    // Tính age
    signal age;
    age <== current_year - birth_year;

    // Cần chứng minh: age >= min_age
    // Dùng circomlib's GreaterEqThan
    component gte = GreaterEqThan(8);  // 8 bits → support 0..255
    gte.in[0] <== age;
    gte.in[1] <== min_age;

    // Constraint: phải true (= 1)
    gte.out === 1;
}

component main {public [current_year, min_age]} = AgeProof();
```

**Giải thích `GreaterEqThan(8)`**: Template này từ circomlib kiểm tra $a \geq b$ bằng cách decompose difference thành bits. `8` là số bits → support values 0..255. Tuổi $\leq 120$ nên 8 bits đủ.

## Bước 4: Generate Witness và Prove

```bash
# Input: người sinh năm 2000, năm hiện tại 2026, min_age = 18
cat > input.json << 'EOF'
{
    "birth_year": "2000",
    "current_year": "2026",
    "min_age": "18"
}
EOF

# Witness
node build/age_proof_js/generate_witness.js \
    build/age_proof_js/age_proof.wasm \
    input.json witness.wtns

# Prove
snarkjs groth16 prove build/age_proof_final.zkey witness.wtns proof.json public.json

cat public.json
# ["2026", "18"]   ← current_year, min_age (public)
```

## Bước 6: On-chain Verifier

```bash
# Export Solidity verifier
snarkjs zkey export solidityverifier build/age_proof_final.zkey contracts/AgeVerifier.sol

# Get calldata
snarkjs zkey export soliditycalldata public.json proof.json
```

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.0;

import "./AgeVerifier.sol";  // generated by snarkjs

contract AgeGate {
    Verifier public verifier;

    constructor(address _verifier) {
        verifier = Verifier(_verifier);
    }

    // Chỉ cho phép access nếu proof hợp lệ
    function accessService(
        uint[2] memory a,
        uint[2][2] memory b,
        uint[2] memory c,
        uint[2] memory input  // [current_year, min_age]
    ) external view returns (bool) {
        // Verify proof on-chain
        require(verifier.verifyProof(a, b, c, input), "Age proof invalid");
        
        // Kiểm tra public inputs khớp với expected values
        require(input[0] == 2026, "Wrong year");
        require(input[1] == 18, "Wrong min age");
        
        return true;
    }
}
```

> [!warning] Thiếu Context Binding
> Contract trên còn một lỗ hổng: proof không được binding đến user address. Bất kỳ ai cũng có thể **replay** proof này. Fix: thêm `address user` vào public inputs của circuit.

## Circuit cải tiến với nullifier (chống replay)

```circom
pragma circom 2.0.0;

include "node_modules/circomlib/circuits/comparators.circom";
include "node_modules/circomlib/circuits/poseidon.circom";

template AgeProofWithNullifier() {
    signal input birth_year;
    signal input secret;        // random secret của user
    signal input current_year;
    signal input min_age;
    signal output nullifier;    // public output: commitment để detect replay

    // Age check (như trước)
    signal age;
    age <== current_year - birth_year;
    component gte = GreaterEqThan(8);
    gte.in[0] <== age;
    gte.in[1] <== min_age;
    gte.out === 1;

    // Nullifier = Poseidon(birth_year, secret)
    // Unique per user, không lộ birth_year
    component hasher = Poseidon(2);
    hasher.inputs[0] <== birth_year;
    hasher.inputs[1] <== secret;
    nullifier <== hasher.out;
}

component main {public [current_year, min_age]} = AgeProofWithNullifier();
// nullifier là public output (từ signal output)
```

Contract check nullifier để chống replay:

```solidity
mapping(uint => bool) public usedNullifiers;

function accessService(..., uint nullifier) external {
    require(!usedNullifiers[nullifier], "Proof already used");
    require(verifier.verifyProof(...), "Invalid proof");
    usedNullifiers[nullifier] = true;
    // grant access
}
```

## Summary

- **Age proof** là use case điển hình: prove range constraint mà không lộ value
- `GreaterEqThan` từ circomlib handle range check; cần chọn đúng số bits
- Witness generation **fail tại runtime** nếu constraint violated → proof không thể tạo
- On-chain verifier cần **bind proof đến context** (user address, timestamp) để chống replay
- **Nullifier pattern**: Poseidon(private_data, secret) → public output để detect reuse
