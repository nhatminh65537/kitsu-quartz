## 3. Ký Hiệu Đặc Biệt Trong Jazz Lead Sheets

| Ký hiệu | Ý nghĩa | Ví dụ |
|---------|---------|-------|
| `/` (slash) | Bass note khác root | C/E = C major, bass E |
| `sus4` | 3rd thay bằng 4th | Csus4 = C–F–G |
| `sus2` | 3rd thay bằng 2nd | Csus2 = C–D–G |
| `add9` | Thêm 9th (không có 7th) | Cadd9 = C–E–G–D |
| `6` | Thêm 6th (thay 7th) | C6 = C–E–G–A |
| `6/9` | Thêm 6th + 9th (không 7th) | C6/9 = C–E–G–A–D |
| `(♭5)` hoặc `♭5` | Diminished 5th trong chord | C7♭5 = C–E–G♭–B♭ |
| `+` hoặc `aug` | Augmented 5th | Caug = C–E–G# |
| `°` hoặc `dim` | Diminished triad | C° = C–E♭–G♭ |
| `△` | Major 7th (jazz shorthand) | CΔ = Cmaj7 |
| `–` hoặc `m` | Minor | C– = Cm |
| `ø` | Half-diminished | Cø = Cm7♭5 |

## 4. Roman Numeral Ký Hiệu Đầy Đủ

| Ký hiệu | Ý nghĩa |
|---------|---------|
| Uppercase (I, II, IV...) | Major chord |
| Lowercase (i, ii, iv...) | Minor chord |
| ° (sau numeral) | Diminished |
| + (sau numeral) | Augmented |
| 7 (sau numeral) | Seventh chord |
| ♭ (trước numeral) | Root flatten so với major scale |
| # (trước numeral) | Root raised so với major scale |
| /X (sau numeral) | Bass note = X |
| [ = ] | Dual Roman numeral (pivot chord notation) |

**Ví dụ đọc:**
- `♭VII7`: chord major trên bậc 7 flatten, thêm minor 7th (= dominant chord)
- `V7/ii`: secondary dominant (V7 dẫn về bậc ii)
- `[vi = ii]`: pivot chord, vi trong key cũ = ii trong key mới
- `♭II6`: Neapolitan sixth (first inversion, bass = ♭2̂)

## 5. Phân Tích Nhanh Chord Từ Lead Sheet

**Bước 1**: Đọc root note (chữ cái đầu: C, D, E♭...)

**Bước 2**: Xác định quality:
- Không có gì thêm → major triad
- `m` hoặc `–` → minor triad
- `7` → dominant 7th
- `maj7` hoặc `△` → major 7th
- `m7` → minor 7th
- `ø` hoặc `m7♭5` → half-diminished
- `°7` → diminished 7th

**Bước 3**: Đọc extensions/alterations sau quality (♭9, #11, 13, alt...)

**Bước 4**: Đọc slash chord nếu có (bass note khác root)
